# Anugerah Prestasi Cemerlang 2026

Laman rasmi paparan bagi Anugerah Prestasi Cemerlang, anjuran Jabatan Penerangan Malaysia. Tema edisi ini ialah **Kompetensi Memacu Prestasi**. Majlis ditetapkan pada 30 November 2026 di Putrajaya International Convention Centre (PICC).

Laman ini dalam Bahasa Melayu. Ia memaparkan kategori, garis panduan, kriteria, tarikh indikatif dan soalan lazim. Borang penyertaan menyimpan draf pada pelayar sahaja dan tidak menghantar data ke pelayan jabatan.

Nama pada halaman senarai penerima diambil daripada direktori awam jabatan sebagai **contoh paparan**. Halaman itu menyatakan nama tersebut bukan penerima anugerah.

## Jalankan secara tempatan

```bash
npm install
npm run dev
```

Pelayan pembangunan menggunakan port `3457`.

```bash
npm run lint
npm run build
npm start
```

## Deploy ke GitHub Pages

Setiap push ke `main` membina laman statik dan menerbitkannya ke GitHub Pages.

https://thaniazura-blip.github.io/apc/

Binaan Pages menggunakan `GITHUB_PAGES=true` dan `NEXT_PUBLIC_BASE_PATH=/apc`. `npm run dev` di mesin sendiri tidak memerlukan pembolehubah itu.
